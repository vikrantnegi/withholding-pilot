The database — three tables, new since last time

deploys

  • deploy_id integer
  • service text — auth, billing, notify, payments, search
  • env text — prod or staging
  • status text — success or failed
  • duration_sec integer

tickets

  • ticket_id integer
  • team text — data, mobile, platform, web
  • priority text — P1, P2, P3
  • status text — open or closed
  • hours_to_close integer

rides

  • ride_id integer
  • city text — Delhi, Indore, Jaipur, Kochi, Pune
  • driver text
  • fare integer
  • distance_km number
  • rating integer — 3 to 5

Nothing here joins to anything. Every question is answerable from one table.
